# dir_operations_demo01

这个 demo 演示的是目录的创建与删除，并且给出了两组“同一操作的不同实现”。

## 涵盖的操作

- 创建目录
- 删除目录

## 方法对比

| 操作 | 方法 | 核心 API | 行为特点 | 适用场景 |
| --- | --- | --- | --- | --- |
| 创建目录 | `Createdir1` | `os.Mkdir` | 只创建单级目录；父目录不存在会失败；目录已存在会报错 | 你明确知道父目录已存在，只想创建一个目录 |
| 创建目录 | `Createdie2` | `os.MkdirAll` | 可一次创建多级目录；父目录不存在也能创建；已有目录通常不会报错 | 初始化多级目录结构（如 `a/b/c`） |
| 删除目录 | `Removedir1` | `os.Remove` | 只能删空目录（也可删文件）；目录非空会失败 | 想保守删除，避免误删整棵目录 |
| 删除目录 | `Removedir2` | `os.RemoveAll` | 递归删除整个目录树，包含所有子目录和文件 | 清理临时目录、重置测试环境 |

## 代码中的关键差异

- `os.Mkdir` 与 `os.MkdirAll` 的核心差异是是否支持“自动补齐父目录”。
- `os.Remove` 与 `os.RemoveAll` 的核心差异是是否递归删除。
- 当前示例传入的权限是 `0666`，目录通常更推荐 `0755`（目录需要执行位 `x` 才能正常进入）。

## 运行方式

在当前目录执行：

```bash
go run .
```

执行流程（`main.go`）：

1. 创建 `testdir1`（单级）
2. 创建 `testdir2/testdir3`（多级）
3. 删除 `testdir1`（普通删除）
4. 递归删除 `testdir2`（连同子目录）

## 建议

- 生产代码里，对 `RemoveAll` 要谨慎，最好先做路径白名单或安全检查，避免误删。
- 如果目录可能已存在，优先用 `MkdirAll`，容错更好。
